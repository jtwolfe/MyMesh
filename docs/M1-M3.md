# M1–M3 design notes

## Identity = transport id

MyMesh long-term keys are 32-byte Ed25519 seeds. The same bytes load into
iroh as `SecretKey`. Therefore:

```text
DeviceId  ==  iroh EndpointId  ==  Ed25519 verifying key bytes
```

After pairing, peers dial with `endpoint.connect(peer_device_id, b"mymesh/1")`.
No separate node id mapping table.

## Pairing mailbox

SPAKE2 needs a short-lived meeting place **before** permanent trust exists.

### Filesystem mailbox (`MYMESH_MAILBOX_DIR` or `--mailbox-dir`)

Per-code, per-direction JSONL files under a shared directory. Ideal for:

- two processes on one machine
- CI integration tests
- no network required

### HTTP mailbox (`mymesh mailbox` + `MYMESH_MAILBOX` URL)

```http
POST /v1/box/{code}/{lane}   body: bincode/json PairingMessage
GET  /v1/box/{code}/{lane}   long-poll next message
```

Lanes: `h2g` (host→guest), `g2h` (guest→host). Messages expire with TTL
(default 10 minutes). Mailbox never sees the long-term private key.

## Session

1. Iroh bi-directional stream carries length-prefixed frames.  
2. Dialer sends `ControlMessage::Hello` (signed).  
3. Acceptor checks device store → `HelloAck`.  
4. Application opens logical channels (terminal stream id, files stream id).

## Serve loop

```text
loop {
  conn = endpoint.accept()
  if !store.is_trusted(conn.remote_id()) { close; continue }
  handshake()
  demux frames → terminal host | file engine
}
```

## Shell

Client opens terminal channel with `TerminalMessage::Open`, then:

- thread: stdin → `Input`
- async: `Output` → stdout
- SIGWINCH / crossterm size → `Resize`

## Files

- Push: local file → `Put` + `Chunk*` + wait `Done`
- Pull: `Get` → receive `Chunk*` + `Done` → write local
- All host paths resolved through `PathSandbox` (default: `$HOME`)
